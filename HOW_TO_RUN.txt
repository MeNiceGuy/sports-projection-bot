Sports Projection Bot - How To Run

Project folder:
C:\Users\1bosw\.openclaw\workspace\sports-projection-bot

1. Open PowerShell in the project folder.
2. Install dependencies:
   python -m pip install -r requirements.txt

3. Run the bot:
   python run_bot.py

4. The report will print in the terminal and also save to:
   reports\daily_projection_report.json

5. To append the current projections into the prediction log and build a basic performance summary:
   python run_performance.py

6. To build the current grading summary structure:
   python run_grader.py

7. To merge completed game results from the template into graded results:
   python run_merge_results.py

8. To build confidence-bucket reporting from graded results:
   python run_confidence_report.py

9. To generate self-audit upgrade suggestions:
   python run_self_audit.py

10. To email strong NBA/MLB projections:
   python run_alerts.py

11. To compare projections against supplied market lines:
   python run_market_compare.py

12. To build the current player-props output:
   python run_props_engine.py
