# Sports Projection Bot Top-Contender Upgrades

## Product Lane

This should compete as a sports projection, validation, and betting-research lab with strict performance tracking.

## Next Decisive Upgrades

- Keep generated data, logs, SQLite files, and reports out of Git.
- Add validation dashboards for hit rate, calibration, Brier score, log loss, CLV, and edge decay.
- Add sample data fixtures so the full pipeline can be demonstrated without live API keys.
- Add source freshness gates for odds, injuries, schedules, and results.
- Add model cards for NBA and MLB explaining features, assumptions, and sample-size limits.

## Launch Boundary

Market it as research tooling, not a betting guarantee. Every output should preserve risk language, sample-size gates, and bankroll constraints.
